# Mini-site LN-IA — Vite (optionnel)

Cette présentation peut être ouverte directement via `index.html` (liens vers les documents HTML inclus). Pour utiliser Vite depuis ce dossier : `npm install`, puis `npm run dev`; pour compiler : `npm run build`. Pour publier sous GitHub Pages, déployer le répertoire `dist/` après vérification de la politique de diffusion ; éviter de publier les CV, devis ou documents confidentiels. Base Vite relative `./`. La reproduction des emblèmes institutionnels est volontairement évitée.
