# Diagnostic initial : méthode et questionnaire

**Moment :** avant la première session. **Livrable attendu :** synthèse agrégée et adaptation du programme, à remettre à la DELM. **[TDR p.2 §III.1-2]**

## Questionnaire de 12 questions (sans données de santé)

1. Profil professionnel : surveillance / suivi-évaluation / administration / finances / coordination / partenaire associatif / autre.
2. Niveau d'aisance informatique : 1 (débutant) à 4 (autonome).
3. Usage de traitement de texte : jamais / occasionnel / régulier.
4. Usage d'Excel : saisie / formules / tableaux croisés / analyse autonome.
5. IA générative déjà utilisée ? jamais / moins d'une fois par mois / hebdomadaire / quotidien.
6. Tâche où l'IA pourrait vous aider : documents / synthèse / tableaux / présentation / reporting / autre.
7. Pouvez-vous distinguer une source vérifiée d'une réponse générée ? oui / partiellement / non.
8. Savez-vous formuler une requête avec contexte, contrainte et format ? oui / partiellement / non.
9. Connaissez-vous les règles SI de votre institution concernant les données ? oui / partiellement / non.
10. Équipement prévu : ordinateur individuel / partagé / besoin d'équipement.
11. Langue de travail souhaitée pour supports : français / arabe / les deux / autre.
12. Quel livrable concret souhaiteriez-vous réaliser à l'issue de la formation ? réponse libre sans mention de cas patient réel.

## Mini-épreuve pratique (20 min)

- A : écrire un prompt demandant un tableau de suivi d'activités inventées.
- B : vérifier une réponse qui indique un pourcentage sans dénominateur.
- C : détecter dans un exemple fictif trois données non admissibles dans un outil public.
